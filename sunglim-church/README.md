# 성림교회 홈페이지

홈 화면 + 모바일 주보 + 관리자 페이지로 된 교회 홈페이지입니다. Netlify 에 올려서 씁니다.

| 페이지 | 내용 |
| --- | --- |
| `index.html` | 홈 — 이번 주 말씀, 유튜브 최신 영상, 예배 시간, 인스타그램 최근 사진, 오시는 길 |
| `bulletin.html` | 주보 — 가장 최근에 공개된 주보. 글자 크기 3단계, 아래에서 지난 주보 선택, PDF로 저장 |
| `calendar.html` | 교회 일정 — 달력. 관리자에서 넣은 일정이 달력과 주보의 ‘교회 일정’에 함께 나옴 |
| `offering.html` | 헌금명단 — 비밀번호를 넣어야 열림. 명단은 주보와 따로 보관되어 비밀번호 없이는 서버에서 내려오지 않음 |
| `admin.html` | 관리자 — 화면에 링크가 없으므로 주소 뒤에 `/admin.html` 을 직접 입력해 로그인 |

## 매주 하는 일 (관리자 페이지)

1. **주보 → + 새 주보 만들기** : 지난주 주보가 복사되고 날짜·호수가 다음 주로 바뀝니다.
2. 설교 제목·본문, 소식, 셀 나눔, 헌금 명단 등 바뀐 부분만 고칩니다. 오른쪽 미리보기에 바로 반영됩니다.
3. 대표기도·2부 성경봉독·‘예배위원/담당’은 **대표기도·봉사 명단**에서, 예배 순서의 ‘말씀암송’은 지난주 암송구절에서 자동으로 불러옵니다.
4. **저장하고 공개**를 누르면 주보 페이지와 홈 화면이 바뀝니다. (임시 저장은 공개 전 상태)
5. **PDF로 저장** : 인쇄 창에서 대상을 ‘PDF로 저장’으로 고르면 A5 책자 형태 PDF로 보관할 수 있습니다.

## 1년치 명단 넣기

**대표기도·봉사 명단 → 엑셀에서 붙여넣기**에 표를 복사해 붙여넣습니다.
칸 순서: `날짜 · 1부 대표기도 · 2부 대표기도 · 2부 성경봉독 · 설거지담당`

## 교회 일정 (달력)

**교회 일정** 탭에서 일정을 넣으면 달력 메뉴와 주보의 ‘교회 일정’에 함께 나옵니다.
‘매주 반복 · N주간’을 고르면 날짜마다 한꺼번에 들어가고, 넣은 뒤에도 날짜 하나만 고치거나 지울 수 있습니다.
목사님 원고의 `교회 일정` 줄도 달력에 없는 것만 자동으로 추가됩니다.

## 생일 명단 (1년치)

**생일 명단**에 이름·월·일을 넣어 두면(엑셀 붙여넣기 가능) 주보에 그 주(주일~토요일) 생일자만 자동으로 나옵니다.
‘음력’에 체크하면 해마다 양력으로 바꿔 계산합니다. 명단 전체는 관리자만 볼 수 있습니다.

## 헌금명단

주보 편집 화면의 **헌금명단** 칸에 적은 이름은 주보에 실리지 않고 ‘헌금명단’ 메뉴에서만 보입니다.
열람 비밀번호는 Netlify 환경 변수 `OFFERING_PASSWORD` 입니다.

## 그 밖에 관리자에서 바꿀 수 있는 것

- **교회 정보** : 주소·전화·계좌·예배 시간, 표어 붓글씨 이미지, 유튜브 채널, 인스타그램 아이디
- **상단 메뉴** : ‘홈’, ‘주보’ 뒤에 붙는 메뉴를 이름 + 링크 주소로 추가 (외부 링크는 새 창)

## 목사님 원고로 채우기

**주보 → 목사님 원고 넣기**에 원고 전체를 붙여넣거나 한글(HWP) 파일을 끌어다 놓으면
설교 제목·본문, 암송말씀, 소식(광고), 셀 나눔과 질문, 교회 일정이 항목별로 들어갑니다.
원고에 `본문_`, `제목_`, `금주의 암송 말씀 – 구절`, `[광고]`(소식은 `*` 로 시작), `셀 나눔`, `교회 일정` 표시가 있어야 합니다.

## 구조 (Netlify)

- `public/` — 사이트 화면 (빌드 없이 그대로 올라감)
- `netlify/functions/` — 저장·로그인 서버 기능 (`/api/*`), 실제 처리는 `netlify/lib/app.mts`
- 저장소는 Netlify Blobs(`sunglim` 저장소)라서 별도 데이터베이스가 필요 없습니다.
- 비밀번호는 코드에 없고 Netlify 환경 변수에 있습니다: 관리자 `ADMIN_PASSWORD`(아이디 `ADMIN_ID`, 기본 `admin`), 헌금명단 열람 `OFFERING_PASSWORD`.
  비밀번호를 바꾸려면 Netlify → Project configuration → Environment variables 에서 고친 뒤 다시 배포합니다.

내 컴퓨터에서 띄워 보기: `ADMIN_PASSWORD=아무거나 OFFERING_PASSWORD=아무거나 node --experimental-strip-types tools/dev-server.mts`
시험: `npm test`
