# 커리어 LLM 위키

1. 먼저 `career-wiki/CLAUDE.md`(운영 규칙)를 읽는다.
2. 그다음 `career-wiki/wiki/index.md`로 전체 페이지를 파악한다.
3. 요청에 따라 CLAUDE.md의 **넣기 / 지원·제안 / 묻기 / 점검** 절차를 그대로 따른다.
4. 끝나면 `index.md`·`log.md`를 갱신하고, 커밋·푸시한다.

공개 저장소이므로 연락처·금액·개인정보는 넣지 않는다(CLAUDE.md 하단 참고).
