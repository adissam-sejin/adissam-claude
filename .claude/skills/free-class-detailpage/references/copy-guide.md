# 무료특강 카피 가이드

흐름: **공감(2) → 배우는 것(3) → 안심 정보(4) → 신청(5)**. 히어로(1)는 썸네일 카피를 그대로 옮긴다.
한 장에 들어갈 분량만 쓴다. 헤드라인 2줄, 말풍선·카드 설명은 1줄(20자 안팎).

## 1. 히어로 (밝음)
- 라벨: `FREE SPECIAL CLASS #NN`
- 칩: "줌 실시간 라이브"
- 부제 2줄: 썸네일 그대로
- 메인 타이틀: 썸네일 그대로
- 회색 날짜 박스: "YYYY.MM.DD(요일) 저녁 9시~10시"
- 칩 2개: "선착순 100명 무료" / "2주 다시보기 제공"
- 하단 작은 글씨: "강사 아는디자이너"
- 그림: 주제 소품을 든 낙서 로봇

## 2. 이런 분께 추천해요 (어두움)
- 칩: "이런 분께 추천해요"
- 헤드라인 2줄, 핵심 단어 하나에 청록 하이라이트. 채팅만 쓰는 초보가 "이것도 돼?" 하고 놀라는 문장.
- 말풍선 4개: 대상의 혼잣말. 4개 중 하나는 이번 주제의 도구/용어 이름을 넣는다.
- 마무리 한 줄: 안심 문구 ("AI 초보도 괜찮아요! 따라만 오세요", "1시간이면 흐름이 한눈에 보여요!")

## 3. 이날 배우는 것 (밝음)
- 칩: "이날 배우는 것"
- 헤드라인 2줄 + 하이라이트 단어
- 카드 3개: `PART 01~03` / 굵은 제목(10자 안팎) / 한 줄 설명 / 오른쪽 낙서 아이콘
  - 실습형은 before→after 낙서가 잘 어울린다
- 하단 회색 강조 바: 이 특강의 한 줄 약속 (사용 도구, 핵심 메시지)
- 사용자가 준 내용이 2개뿐이면 PART 2개로 줄인다. 내용을 지어내 3개를 채우지 않는다(추정했으면 확인 필요 표시).

## 4. 진행 안내 (어두움)
- 칩: "진행 안내"
- 헤드라인: "줌으로 편하게" / "집에서 참여하세요" ("집에서" 하이라이트)
- 흰 카드 표 5행: 일시 / 방식 / 정원 / 다시보기 / 강사
- 준비물 카드 2개(기본: 챗GPT 계정, 제미나이 계정) + 칩 "무료 계정도 OK"
- 하단 주석(필요할 때): "* 챗GPT 무료 사용자는 실습 횟수에 제한이 있을 수 있어요"(실습형) / "…일부 기능에 제한이 있을 수 있어요"(설명형)

## 5. 신청 안내 (밝음)
- 같은 달 특강이 여러 개면: 상단 헤드라인(그 달 사정을 담은 한 줄) + 특강 카드 나란히. 이번 특강 카드는 청록 굵은 테두리 + "이번 강의" 배지, 다른 카드는 회색 테두리 + "다음 주"/"지난주" 배지. 카드 안: #번호, 타이틀, "MM.DD(요일) 저녁 9시", 작은 로봇.
- 단독이면: 헤드라인 "1시간이면 충분해요!" 같은 한 줄 + 이번 특강 요약 카드 하나.
- 큰 글씨 2줄: "M월 D일 요일 밤 9시," / "줌에서 만나요!"
- 회색 박스(버튼 아님): "페이지의 '강의신청'을 눌러 신청해주세요"
