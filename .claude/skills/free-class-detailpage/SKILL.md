# 무료특강 상세페이지 (FREE SPECIAL CLASS)

아는디자이너의 월간 무료특강용 상세페이지를 만든다. 결과물은 **특강 1개당 4:5 세로 이미지 5장**과, 5장을 이어 붙인 **전체 미리보기 1장**이다. 상세페이지는 강의사이트 "눈보라피팅룸"에 올라간다.

특강의 형식은 매번 같고 주제·날짜·배우는 내용만 바뀐다. 그래서 고정 정보는 묻지 않고, 바뀌는 정보만 받아서 빠르게 만든다.

## 고정 정보 (묻지 말고 그대로 쓴다)

| 항목 | 값 |
|---|---|
| 라벨 | `FREE SPECIAL CLASS #회차번호` |
| 진행 방식 | 줌 실시간 라이브 |
| 시간 | 저녁 9시~10시 (21:00~22:00) |
| 정원 | 선착순 100명, 무료 |
| 다시보기 | 라이브 참여 시 2주간 제공 |
| 강사 | `아는디자이너` (이름만, 소개 글 없음) |
| 신청 | 상세페이지 아래 사이트 버튼 "강의신청"을 누르라고 **문구로만** 안내 |
| 대상 | AI에 가입은 했고 채팅으로만 쓰는 일반인 초보 |
| 톤 | 친근하게 |
| 기본 준비물 | 챗GPT 계정, 제미나이 계정 (무료 계정 OK) |

사용자가 이번 특강에 한해 다르게 말하면(시간 변경, 준비물 추가 등) 그 값을 쓴다.

### 하지 말 것
- 이미지 안에 **신청 버튼 모양을 넣지 않는다.** 사이트의 실제 버튼과 헷갈린다. 회색 사각 박스에 "페이지의 '강의신청'을 눌러 신청해주세요" 문구만 넣는다.
- 강사 소개 글, 경력, 사진을 넣지 않는다.
- 신청 혜택(자료 PDF 등)을 지어내지 않는다. 혜택은 "2주 다시보기"뿐이다.
- 실제 기능이 "사라진다"처럼 바뀔 수 있는 사실을 단정하지 않는다. 이미지 글자는 나중에 고칠 수 없으니 "○○ 다음은 '△△'"처럼 부드럽게 쓰고, 단정 표현을 원하면 사용자에게 확인한다.

## 1단계. 받을 정보

사용자 메시지와 첨부에서 아래를 뽑는다. **빠진 것만 한 번에 묻는다.**

| 필수 | 설명 |
|---|---|
| 회차 번호 | 예: #63 |
| 날짜 | 요일이 없으면 직접 계산한다. 연도는 오늘 기준 다가오는 날짜로 잡는다 |
| 메인 타이틀 | 썸네일의 가장 큰 글자 (예: "AI 이미지", "굿바이 챗봇") |
| 부제 2줄 | 썸네일의 타이틀 위 두 줄 |
| 배우는 내용 | 다룰 주제·실습. 정해지지 않았으면 "대략 이런 걸로" 수준이어도 된다 |

| 있으면 좋음 | 설명 |
|---|---|
| 썸네일 이미지 | **있으면 스타일 참고 이미지로 꼭 쓴다.** 없으면 지난 특강 스타일 설명(아래 디자인)으로 만든다 |
| 같은 달 다른 특강 | 있으면 5장째에 시리즈 카드로 함께 보여준다 |
| 이번 회차 특별 사항 | 쉬어간 달, 준비물 차이, 무료 계정 제한 등 |

썸네일에 메인 타이틀·부제·날짜가 다 있으면 그걸 읽어서 쓰고, 다시 묻지 않는다.

## 2단계. 카피 기획

[references/copy-guide.md](references/copy-guide.md)를 읽고 5장 카피를 작성해 대화창에 표로 보여준다. 사용자가 "바로 만들어줘", "이미지까지" 등으로 확인 생략을 원하면 바로 3단계로 간다.

5장 고정 구성(밝음↔어두움 교차):

| # | 섹션 | 배경 |
|---|---|---|
| 1 | 히어로 | 밝음 (썸네일과 같은 파스텔) |
| 2 | 이런 분께 추천해요 | 어두움 (차콜) |
| 3 | 이날 배우는 것 (PART 01~03) | 밝음 |
| 4 | 진행 안내 + 준비물 | 어두움 |
| 5 | 신청 안내 (+ 같은 달 특강 카드) | 밝음 |

배우는 내용이 사용자 설명에 없어서 추정해 넣은 항목은 "확인 필요"로 표시한다.

## 3단계. 디자인

썸네일과 같은 결을 유지한다.

- **밝은 장**: 민트→피치 파스텔 그라데이션 종이 배경(잔 그레인), 히어로는 오른쪽 위 종이 말림
- **어두운 장**: 차콜 `#2A2A2E` 배경, 흰 글씨, 흰 선 낙서
- **강조**: 청록 `#14907F` (라벨 칩, 하이라이트 박스, PART 칩)
- **회색 박스**: `#8F8987` 사각 박스 + 흰 글씨 (날짜, 하단 강조 바, 신청 안내)
- **타이포**: 아주 굵은 검정 한글 고딕, 가운데 정렬
- **그림**: 손그림 검정 선 + 흰 몸통의 귀여운 로봇 낙서. 주제에 맞는 소품을 든다 (이미지 → 붓, 비서 → 헤드셋)

## 4단계. 힉스필드 생성

1. `ToolSearch`로 `mcp__Higgsfield__generate_image_batch`, `generate_image`, `jobs_wait`, `show_generation_by_ids`, `balance`, `media_upload`, `media_confirm`을 불러온다.
2. **썸네일 업로드**: `media_upload`(filename, image/png) → 받은 `upload_url`에 `curl -X PUT -H "Content-Type: image/png" --data-binary @<파일> '<upload_url>'` → HTTP 200 확인 → `media_confirm(type:"image")`. 첨부 이미지 경로는 대화의 업로드 경로를 쓴다.
3. **비용 확인**: `generate_image`에 `get_cost: true`로 장당 비용을 확인하고 `balance`와 함께 "총 N장 × 장당 비용 = 예상 크레딧, 잔액"을 알린다. (기준: `gpt_image_2_5`, 4:5, high, 2k → 장당 2.75크레딧, 5장 13.75)
4. **프롬프트**: [references/prompts.md](references/prompts.md)의 섹션별 템플릿에 카피를 채운다. 모든 요청에 썸네일 media_id를 `role: "image_references"`로 넣는다.
   - 한글 문구는 모두 큰따옴표 안에 정확히 적고, 제출 전에 따옴표 안 한글 맞춤법을 한 번 더 읽는다.
   - 파라미터: `model: "gpt_image_2_5"`, `aspect_ratio: "4:5"`, `quality: "high"`, `resolution: "2k"`
5. **제출**: `generate_image_batch` 한 번에 제출한다. 특강 2개(10장)를 한꺼번에 보내면 1~2장이 `429 rate_limit_reached`로 실패하곤 한다. **실패한 index만** 같은 프롬프트로 다시 보낸다. 성공한 건 다시 보내지 않는다(중복 과금).
6. `jobs_wait`(15초)로 끝날 때까지 확인한다. 기다리는 동안 진행 상황을 짧게 알린다.

## 5단계. 한글 검수

```bash
python3 <skill-dir>/scripts/fetch_and_preview.py <저장폴더> <스크래치패드>/preview "63_01_히어로.png=URL" "63_02_추천대상.png=URL" ...
```

- 미리보기를 `Read`로 **한 장씩 전부** 열어 프롬프트 문구와 글자 단위로 비교한다.
- 오타·깨진 글자·빠진 문구가 있으면 그 장만 다시 생성한다.
- 그림 속 실제 브랜드 로고(예: 노트북 화면의 챗GPT 로고)가 나오면 다시 만들지 말고 사용자에게 알린다.

## 6단계. 조립과 전달

```bash
python3 <skill-dir>/scripts/assemble_page.py <저장폴더> <저장폴더>/63_01_히어로.png ... <저장폴더>/63_05_신청안내.png
```

- 저장폴더: 작업 디렉터리 아래 `무료특강_<회차>_<메인타이틀 공백 제거>/` (예: `무료특강_63_AI영상/`)
- `show_generation_by_ids`로 갤러리를 보여주고, `SendUserFile`로 `상세페이지_전체.jpg`를 보낸다.
- git 저장소에서 작업 중이고 지정 브랜치가 있으면 커밋·푸시한다.
