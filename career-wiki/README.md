# 커리어 LLM 위키 — 아는디자이너 김세진

AI가 내 자료를 위키로 정리하고 계속 키워 가는 커리어 저장소. 운영 규칙은 [CLAUDE.md](CLAUDE.md), 목차는 [wiki/index.md](wiki/index.md).

## 이렇게 쓰세요 (Claude에게 말하기)
| 하고 싶은 것 | 이렇게 말하기 |
|---|---|
| 자료 넣기 | 파일을 `inbox/`에 올리고 "위키에 넣어줘" (사진·캡처·메모·후기 아무거나) |
| 강의 끝난 뒤 | "오늘 ○○도서관 강의 끝났어. 20명, 반응 좋았고 …" → 경험 카드 생성 |
| 제안 준비 | "○○평생학습관에 AI 그림책 강의 제안하려고" → 기관 페이지 → 제안서 → 맞춤 웹 |
| 묻기 | "시니어 기관에 낼 이력 골라줘", "AI 영상 강의 몇 군데서 했지?" |
| 점검 | "위키 점검해줘" |

GitHub에서 바로 읽을 수 있고, 폴더째 Obsidian으로 열어도 링크가 그대로 동작합니다.
