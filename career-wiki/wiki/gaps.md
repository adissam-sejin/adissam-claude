# 비어 있는 정보 · 확인할 것

채울수록 제안서가 강해진다. 사진·메모·후기를 `inbox/`에 넣고 "위키에 넣어줘"라고 하면 Claude가 해당 카드에 반영한다.

## 1순위 — 숫자 (제안서에서 가장 힘이 셈)
- [ ] 누적 수강생 수, 누적 강의 시간/회차
- [ ] 기관별 만족도 결과 (특히 데이원컴퍼니 기업 강의, 50플러스)
- [ ] 재계약·재요청 기관 (같은 기관에서 2번 이상 부른 곳)
- [ ] 무료특강 회차별 신청·참여 인원

## 2순위 — 증거
- [ ] 강의 현장 사진 (얼굴 안 나온 것), 수강생 결과물, 도서관 전시 사진
- [ ] 수강생 후기 캡처 (실명 가리기)
- [ ] 오브북 출간 도서 목록
- [ ] 디자인 대표 작업 (북디자인 등)

## 3순위 — 빈칸
- [ ] 모어랭귀지스 대표강사 — 무슨 강의를 맡는지
- [ ] 자격증별 취득 연월
- [ ] 인스타 카드뉴스 시작 시기, 팔로워 수
- [ ] 대학별 과목명·학기
