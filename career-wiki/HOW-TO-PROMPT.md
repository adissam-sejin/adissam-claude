# 나만의 커리어 LLM 위키 + 포트폴리오 사이트 만들기 — Claude Code 프롬프트

아래 프롬프트를 Claude Code에 그대로 붙여 넣고, `[ ]` 칸만 내 정보로 바꾸세요.
이력서·자기소개서·강의계획서·포트폴리오 PDF처럼 가진 자료를 같이 올리면 결과가 훨씬 좋아집니다.

---

## 전체 프롬프트 (복사해서 쓰기)

```
내 커리어와 포트폴리오를 담은 "LLM 위키"와, 그 위키에서 자동으로 만들어지는 포트폴리오 웹사이트를 만들어줘.
LLM 위키는 AI가 내 자료를 마크다운 위키로 정리하고, 내가 자료를 넣을 때마다 계속 키워 가는 방식이야.

## 나에 대해
- 이름 / 활동명: [홍길동 / ○○디자이너]
- 하는 일: [예: 기업·기관 대상 AI 강의, UX 디자인, 마케팅 컨설팅]
- 앞으로 쓰고 싶은 곳: [예: 기관 강의 제안, 이직 지원, 외주 영업]
- 브랜드 컬러: [예: 빨강 #E1251A] / 폰트: [있으면 적기, 없으면 추천해줘]
- 공개해도 되는 연락처: [예: 인스타 @…, 홈페이지 주소] (전화·이메일은 넣지 마)
- 첨부한 자료: [이력서.pdf, 강의이력.xlsx, 메모 등]

## 1단계 — 위키 구조 만들기
career-wiki/ 폴더에 아래 구조로 만들어줘.
- inbox/ : 수집함. 파일·캡처·메모·후기를 그냥 던져 넣는 곳 (AI는 읽기만 하고 고치지 않음)
- wiki/cards/ : 경험 카드. 경험 하나당 한 장. "한 일 / 결과 / 증거 / 제안서에 쓸 한 줄" 칸
- wiki/competencies/ : 역량 페이지. 역량별로 경험 카드를 묶어 둠
- wiki/orgs/ : 지원·제안할 회사·기관 페이지 템플릿 (문제 정의, 톤, 앞세울 카드, 결과)
- wiki/works/ : 내가 만든 제안서·지원서·시안 기록
- wiki/profile/ : 정체성·브랜드, 경력 타임라인, 자격증
- wiki/index.md(목차), overview.md(한 장 요약), log.md(작업 기록), gaps.md(비어 있는 정보)
- career-wiki/CLAUDE.md : 이 위키 운영 규칙 (넣기 / 묻기 / 지원 준비 / 점검 절차)

규칙:
- 첨부 자료에 없는 사실은 절대 지어내지 마. 모르는 값은 "(확인 필요)"로 쓰고 gaps.md에 올려.
- 카드의 "결과"는 숫자 우선(인원, 회차, 만족도, 재계약, 성과).
- 링크는 상대경로 마크다운 링크로 (GitHub와 Obsidian에서 둘 다 열리게).
- 저장소가 공개라면 전화번호·이메일·주소·생년·금액·남의 실명은 넣지 마.

첨부 자료를 읽고 경험 카드와 역량 페이지를 채워줘. 다 하면 무엇을 만들었는지,
가장 먼저 채우면 좋은 빈칸이 뭔지 알려줘.

## 2단계 — 포트폴리오 사이트 생성기
career-wiki/scripts/build_site.py 를 만들어서 위키(카드·역량·경력·자격증)를 읽어
한 장짜리 포트폴리오 사이트(sites/portfolio/index.html)를 만들게 해줘.
- "(확인 필요)"가 들어간 내용은 사이트에 내보내지 마.
- 위키를 고치고 스크립트를 다시 돌리면 사이트가 갱신되는 구조로.

디자인:
- 흑백 에디토리얼 컨셉: 굵은 고딕 + 가는 세리프를 겹친 큰 제목, 01~05 번호 섹션,
  어두운/밝은 밴드 교차, 종이 질감. 내 브랜드 컬러는 포인트로만.
- [레퍼런스 이미지가 있으면 첨부하고 "이 컨셉으로"라고 적기]
- 섹션: 첫 화면(이름·한 줄 소개·핵심 숫자) / 소개 / 역량 / 경험 카드 / 대상·고객별 강점 / 경력·자격 / 문의
- 휴대폰에서도 깨지지 않게.

인터랙션:
- 첫 화면 큰 글자가 마우스를 따라 살짝 움직이는 효과
- 포인트 컬러 점 커서 (카드 위에선 커지며 "VIEW")
- 스크롤하면 나타나는 상단 메뉴 + 읽은 만큼 차는 진행바
- 고객·기관 이름이 옆으로 흐르는 띠
- 역량 행을 클릭하면 펼쳐져 관련 경험 목록, "이 역량의 경험만 보기"로 필터
- 경험 카드 클릭 시 상세 창 (←/→로 넘기기, Esc로 닫기)
- 움직임 줄이기 설정을 켠 사람에겐 애니메이션 끄기

만들고 나면 브라우저로 직접 열어서 클릭 동작을 확인하고 스크린샷을 보여줘.

## 3단계 — 파비콘·오픈그래프 + 배포
- 브랜드 톤으로 파비콘(ico, 16/32px, 애플 터치 아이콘)과
  오픈그래프 이미지(1200×630)를 만들어서 사이트 head에 태그를 넣어줘.
- Netlify에 배포해줘. 프로젝트 이름은 [원하는 이름]으로 하고,
  이미 있는 이름이면 비슷한 걸로 정한 뒤 알려줘. 배포 후 실제 주소에서 열리는지 확인해줘.

## 앞으로 쓰는 법도 CLAUDE.md에 적어줘
- "이거 위키에 넣어줘" → 카드 갱신 → 사이트 다시 만들고 재배포
- "○○에 지원하려고" → 기관 페이지 → 맞는 카드로 지원서·제안서
- "위키 점검해줘" → 모순·빈칸·오래된 정보 찾기

단계마다 끝나면 결과를 보여주고 다음 단계로 넘어가기 전에 확인받아줘.
작업은 git에 커밋해줘.
```

## 짧은 버전 (빠르게 시작하고 싶을 때)

```
첨부한 내 이력 자료로 커리어 LLM 위키를 만들어줘.
구조: inbox(수집함) → cards(경험 카드: 한 일/결과/증거) → competencies(역량별 묶음)
→ orgs(지원할 곳) → works(작업물), 운영 규칙은 CLAUDE.md에.
없는 사실은 지어내지 말고 "(확인 필요)"로 표시해.
그다음 위키를 읽어 포트폴리오 사이트를 자동 생성하는 스크립트를 만들고
(흑백 에디토리얼 디자인, 내 브랜드 컬러 [색]은 포인트, 클릭하면 펼쳐지는 인터랙션),
파비콘·오픈그래프까지 넣어서 Netlify에 배포해줘.
```

## 준비하면 좋은 것

| 준비물 | 왜 필요한가 |
|---|---|
| 이력서·경력기술서 | 경험 카드의 뼈대 |
| 성과 숫자 (인원, 매출, 만족도, 재계약) | 카드의 "결과" 칸. 설득력이 가장 센 정보 |
| 현장 사진·작업물 이미지 | 카드의 "증거" 칸, 사이트 이미지 |
| 흑백 프로필 사진 | 첫 화면과 오픈그래프 이미지에 들어가면 완성도가 확 오름 |
| 마음에 드는 사이트 캡처 1~2장 | 디자인 방향을 정확히 전달 |
| Netlify 계정 (Claude에 연결) | 배포용. 없으면 Claude가 다른 방법을 안내 |

## 팁
- 한 번에 완벽하게 만들려고 하지 말고, 1단계 위키부터 만든 뒤 자료를 계속 넣어 키우세요.
- 강의·프로젝트가 끝날 때마다 "오늘 ○○ 끝났어, 20명, 반응 좋았어"처럼 말로 남기면 카드가 쌓입니다.
- 지원·제안할 때마다 결과(선정·탈락·이유)를 기관 페이지에 남기면 다음 지원이 점점 쉬워집니다.
