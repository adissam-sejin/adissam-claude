# 인스타 → 노션 정리

인스타그램에서 내려받은 "내 정보 내보내기" 파일(JSON)을 올리면
**받은 DM**과 **저장한 게시물**을 노션 데이터베이스로 정리해 주는 사이트입니다.

인스타그램 공식 API는 개인 계정의 DM과 저장한 게시물을 제공하지 않아서,
계정에 로그인하는 방식 대신 인스타그램이 직접 만들어 주는 내보내기 파일을 사용합니다.

## 실행

```bash
npm start        # http://localhost:3000 (Node 18 이상, 설치할 패키지 없음)
```

Vercel에 올릴 때는 이 폴더를 프로젝트 루트로 지정하면 됩니다
(`public/`은 정적 파일, `api/notion.js`는 서버리스 함수로 동작).

## 사용 순서

1. 노션에서 API 통합을 만들고, 정리할 페이지에 그 통합을 연결합니다.
2. 인스타그램 **설정 → 계정 센터 → 내 정보 및 권한 → 내 정보 내보내기**에서
   메시지·저장된 항목을 **JSON** 형식으로 내보냅니다.
3. 받은 ZIP을 사이트에 올리고, 정리할 대화를 고른 뒤 **노션에 정리하기**를 누릅니다.

## 노션에 만들어지는 것

| 데이터베이스 | 한 줄 | 속성 | 본문 |
| --- | --- | --- | --- |
| 인스타그램 받은 DM | 대화 1개 | 보낸 사람, 받은 메시지 수, 첫/마지막 메시지, 구분, 유형 | 날짜별로 묶은 받은 메시지 |
| 인스타그램 저장한 게시물 | 게시물 1개 | 작성자, 링크, 저장일, 컬렉션, 종류 | 게시물 임베드와 링크 |

다시 실행하면 이미 들어간 게시물과 변동 없는 대화는 건너뛰고,
새 메시지가 생긴 대화만 새로 씁니다.

## 알아둘 점

- 내보내기 파일은 브라우저 안에서만 읽습니다. 서버(`api/notion.js`)는 노션 API로
  요청을 전달만 하며 토큰이나 내용을 저장하지 않습니다.
- 인스타그램은 저장한 게시물의 링크·작성자·저장일만 내보냅니다. 캡션 본문은 들어 있지 않습니다.
- 사진·동영상·음성 DM은 개수만 표시됩니다.
- 내보내기 형식이 HTML이면 읽을 수 없습니다. JSON으로 다시 내보내야 합니다.
