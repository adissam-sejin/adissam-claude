Instagram → Notion

받은 DM과 저장한 게시물을
노션에 한 번에 정리

인스타그램에서 내려받은 내 정보 파일을 올리면, 받은 메시지와 저장한 게시물을 노션 데이터베이스로 만들어 드립니다. 파일은 이 브라우저 안에서만 읽고, 노션으로만 전송합니다.

1노션 연결

토큰은 어떻게 만드나요?
  1. notion.so/profile/integrations에서 새 API 통합을 만들고 프라이빗 API 통합 시크릿을 복사합니다.
  2. 노션에서 정리 결과를 넣을 페이지를 하나 만듭니다.
  3. 그 페이지 오른쪽 위 ⋯ → 연결에서 방금 만든 통합을 추가합니다.
  4. 페이지 링크를 복사해 아래에 붙여 넣습니다.

2인스타그램 파일 올리기

파일은 어디서 받나요?
  1. 인스타그램 앱 설정 → 계정 센터 → 내 정보 및 권한 → 내 정보 내보내기로 들어갑니다.
  2. 내보내기 만들기 → 기기로 내보내기를 선택합니다.
  3. 정보 맞춤 설정에서 메시지와 저장된 항목만 남기면 파일이 훨씬 작아집니다.
  4. 형식을 반드시 JSON으로 바꾸고, 기간은 전체 기간으로 둡니다.
  5. 준비가 끝나면(몇 분~몇 시간) 받은 ZIP 파일을 그대로 아래에 올립니다.
ZIP 파일을 여기에 끌어다 놓거나 눌러서 선택 여러 개로 나뉜 ZIP은 한꺼번에 선택하세요

3정리할 내용 확인

      4진행 상황

        저장한 게시물은 인스타그램이 링크·작성자·저장일만 내보내기 때문에, 노션에는 게시물이 임베드와 링크로 들어갑니다. 사진·동영상 DM은 개수만 표시됩니다.
