# 메시지 나무 🎄 🍊 🌸

코드를 입력하고 이름·내용을 남기면 나무 한 그루에 카드가 달리는 사이트입니다.

| 콘셉트 | 달리는 모양 | 용도 |
| --- | --- | --- |
| 크리스마스 트리 | 여러 색의 동그란 오너먼트 볼 | 크리스마스 카드 |
| 감사 감나무 | 주황색 감 | 감사한 일 적기 |
| 벚꽃나무 | 벚꽃 | 소감·리뷰 |

모양 안에 작성자 이름이 보이고, 누르면 메시지가 크게 열립니다. PC·모바일 반응형입니다.

## 화면

- `index.html` — 사용자 화면. 코드 입력 → 나무 보기 → 카드 쓰기 (`index.html?code=코드` 로 바로 입장 가능)
- `admin.html` — 관리자 화면
  - 코드로 나무 생성 (직접 입력 또는 자동 생성)
  - 나무 이름, 콘셉트(3종), 작성 기간(시작~종료) 설정·수정
  - 전체 나무 수 / 전체 카드 수 / 나무별 카드 수 확인
  - 링크 복사, 카드 개별 삭제, 나무 삭제

작성 기간 밖에는 카드를 쓸 수 없고, 달린 카드는 계속 볼 수 있습니다.

## 구조

- 화면: `index.html`, `admin.html` (빌드 과정 없는 정적 파일)
- 서버: `api/tree.js` — 브라우저와 노션 사이에서 읽고 쓰는 서버 함수 (Vercel Serverless Function)
- 저장소: 노션의 **메시지 나무** 페이지 안 DB 두 개
  - **나무** — 나무 이름, 코드, 콘셉트, 작성 시작, 작성 종료, 카드 수
  - **카드** — 이름, 내용, 나무(연결), 작성 시각

노션 API는 브라우저에서 직접 부를 수 없고 시크릿 키도 노출되면 안 되므로, 서버 함수가 중간에서 대신 호출합니다.

## 배포 (Vercel)

1. 노션에서 통합(Integration) 만들기: <https://www.notion.so/profile/integrations> → 새 통합 → 시크릿 복사
2. 노션의 **메시지 나무** 페이지 → 오른쪽 위 `···` → 연결(Connections) → 방금 만든 통합 추가
3. Vercel에 이 저장소를 가져오고 **Root Directory 를 `tree-cards`** 로 지정
4. Vercel 환경 변수 두 개 추가
   - `NOTION_TOKEN` — 1번에서 복사한 시크릿
   - `ADMIN_PASSWORD` — 관리자 화면 비밀번호 (길고 추측하기 어렵게)
5. 배포

DB를 다른 곳으로 옮겨 새로 만들었다면 `NOTION_TREES_DB`, `NOTION_CARDS_DB` 환경 변수에 새 DB ID를 넣으면 됩니다.

## 미리보기 모드

내 컴퓨터(localhost)에서 열면 서버 없이 동작하는 미리보기 모드가 됩니다.
데이터가 **그 브라우저에만** 저장되므로 디자인·동작 확인용입니다. 관리자 비밀번호는 `admin1234`.

```bash
cd tree-cards && python3 -m http.server 8000
```

## 노션에서 직접 고칠 때

- 나무 이름·기간·콘셉트는 노션에서 고쳐도 사이트에 반영됩니다. **코드**와 속성 이름은 바꾸지 마세요.
- 작성 종료를 시간 없이 날짜만 넣으면 그날 밤 11시 59분(한국 시간)까지로 봅니다.
- 카드 행을 노션에서 지우면 나무에서도 사라집니다.

## 참고

- 이름 최대 12자, 내용 최대 500자
- 카드가 많아지면 모양이 작아지고, 그래도 넘치면 나무가 커져 좌우로 밀어 볼 수 있습니다
- 나무 화면은 15초마다 새 카드를 자동으로 반영합니다. 다른 사람이 쓴 카드는 최대 20~30초 뒤에 보일 수 있어요
- 관리자 화면에서 나무를 삭제하면 나무만 노션 휴지통으로 가고, 그 나무의 카드 행은 노션에 남습니다
- 도배 방지(작성 횟수 제한)는 들어 있지 않습니다. 부적절한 카드는 관리자 화면의 "카드 관리"에서 삭제하세요
