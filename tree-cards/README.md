# 메시지 나무 🎄 🍊 🌸

코드를 입력하고 이름·내용을 남기면 나무 한 그루에 카드가 달리는 사이트입니다.

| 콘셉트 | 달리는 모양 | 용도 |
| --- | --- | --- |
| 크리스마스 트리 | 여러 색의 동그란 오너먼트 볼 | 크리스마스 카드 |
| 감사 감나무 | 주황색 감 | 감사한 일 적기 |
| 벚꽃나무 | 벚꽃 | 소감·리뷰 |

모양 안에 작성자 이름이 보이고, 누르면 메시지가 크게 열립니다. PC·모바일 반응형입니다.

## 화면

- `index.html` — 사용자 화면. 코드 입력 → 나무 보기 → 카드 쓰기 (`index.html?code=코드` 로 바로 입장 가능)
- `admin.html` — 관리자 화면
  - 코드로 나무 생성 (직접 입력 또는 자동 생성)
  - 나무 이름, 콘셉트(3종), 작성 기간(시작~종료) 설정·수정
  - 전체 나무 수 / 전체 카드 수 / 나무별 카드 수 확인
  - 링크 복사, 카드 개별 삭제, 나무 삭제

작성 기간 밖에는 카드를 쓸 수 없고, 달린 카드는 계속 볼 수 있습니다.

## 구조

- 화면: `index.html`, `admin.html` (빌드 과정 없는 정적 파일)
- 실시간 저장소: Supabase 프로젝트 `message-tree`
  - 화면이 Supabase 에 바로 읽고 쓰고, Realtime 으로 새 카드를 다른 화면에 즉시 알립니다
  - 표는 노출되지 않는 `msgtree` 스키마에 있고, 바깥에는 `mt_` 로 시작하는 함수만 열려 있습니다
- 기록 보관: 노션의 **메시지 나무** 페이지 안 DB 두 개 (나무 / 카드)
  - `notion-sync` 서버 함수가 10초마다 새 나무·카드를 노션으로 옮겨 적습니다 (초당 3건 정도)
  - 관리자 화면에서 지운 것은 노션에서도 휴지통으로 갑니다
  - 방향은 Supabase → 노션 한쪽입니다. 노션에서 고친 내용은 사이트에 반영되지 않습니다

파일
- `supabase/schema.sql` — 표와 함수
- `supabase/cron.sql` — 10초마다 노션 복사를 확인하는 예약 작업
- `supabase/functions/notion-sync/index.ts` — 노션 복사 서버 함수

## 처음 설정할 때 필요한 것

1. **관리자 비밀번호** — Supabase 대시보드 → SQL Editor 에서 한 번 실행 (8자 이상)
   ```sql
   select public.mt_set_admin_password('원하는-관리자-비밀번호');
   ```
2. **노션 연결**
   - <https://www.notion.so/profile/integrations> 에서 통합을 만들고 시크릿 복사
   - 노션 **메시지 나무** 페이지 → `···` → 연결 → 만든 통합 추가
   - Supabase 대시보드 → Edge Functions → Secrets 에 `NOTION_TOKEN` 이름으로 시크릿 저장
3. **호스팅** — `tree-cards` 폴더를 Vercel / Netlify 같은 정적 호스팅에 올리기

## 미리보기 모드

`js/config.js` 의 `SUPABASE_URL` 을 비우면 서버 없이 동작하는 미리보기 모드가 됩니다.
데이터가 그 브라우저에만 저장되며 관리자 비밀번호는 `admin1234` 입니다.

## 참고

- 이름 최대 12자, 내용 최대 500자
- 카드가 많아지면 모양이 작아지고, 그래도 넘치면 나무가 커져 좌우로 밀어 볼 수 있습니다
- 다른 사람이 쓴 카드는 1~2초 안에 나무에 나타납니다. 알림을 놓쳐도 12초마다 다시 확인합니다
- 도배 방지(작성 횟수 제한)는 들어 있지 않습니다. 부적절한 카드는 관리자 화면의 "카드 관리"에서 삭제하세요
