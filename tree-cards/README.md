# 메시지 나무 🎄 🍊 🌸

코드를 입력하고 이름·내용을 남기면 나무 한 그루에 카드가 달리는 사이트입니다.

| 콘셉트 | 달리는 모양 | 용도 |
| --- | --- | --- |
| 크리스마스 트리 | 여러 색의 동그란 오너먼트 볼 | 크리스마스 카드 |
| 감사 감나무 | 주황색 감 | 감사한 일 적기 |
| 벚꽃나무 | 벚꽃 | 소감·리뷰 |

모양 안에 작성자 이름이 보이고, 누르면 메시지가 크게 열립니다. PC·모바일 반응형입니다.

## 화면

- `index.html` — 사용자 화면. 코드 입력 → 나무 보기 → 카드 쓰기 (`index.html?code=코드` 로 바로 입장 가능)
- `admin.html` — 관리자 화면
  - 코드로 나무 생성 (직접 입력 또는 자동 생성)
  - 나무 이름, 콘셉트(3종), 작성 기간(시작~종료) 설정·수정
  - 전체 나무 수 / 전체 카드 수 / 나무별 카드 수 확인
  - 링크 복사, 카드 개별 삭제, 나무 삭제

작성 기간 밖에는 카드를 쓸 수 없고, 달린 카드는 계속 볼 수 있습니다.

## 미리보기 모드 (설정 없이 바로 실행)

`js/config.js` 의 Supabase 값이 비어 있으면 미리보기 모드로 동작합니다.
데이터가 **그 브라우저에만** 저장되므로 디자인·동작 확인용입니다. 관리자 비밀번호는 `admin1234`.

```bash
cd tree-cards && python3 -m http.server 8000
```

실행 후 `http://localhost:8000/admin.html` 에서 나무를 만들고 코드로 입장해 보세요.

## 실제 운영 (여러 사람이 함께 쓰기)

여러 사람의 카드가 한 나무에 모이려면 서버 저장소가 필요합니다. Supabase(무료 요금제 가능)를 씁니다.

1. Supabase 프로젝트를 만들고 **SQL Editor** 에 `supabase/schema.sql` 전체를 붙여넣어 실행
2. 같은 곳에서 관리자 비밀번호 설정 (8자 이상, 길게)
   ```sql
   select public.set_admin_password('원하는-관리자-비밀번호');
   ```
3. `js/config.js` 에 프로젝트 URL 과 anon(publishable) 키 입력
4. `tree-cards` 폴더를 Netlify / Vercel / GitHub Pages 같은 정적 호스팅에 올리기 (빌드 과정 없음)

anon 키는 공개돼도 되는 키입니다. 테이블은 직접 접근이 막혀 있고(RLS), 모든 읽기·쓰기는
`schema.sql` 의 함수로만 이뤄지며 관리자 기능은 비밀번호를 서버에서 확인합니다.

## 참고

- 이름 최대 12자, 내용 최대 500자
- 카드가 많아지면 모양이 작아지고, 그래도 넘치면 나무가 커져 좌우로 밀어 볼 수 있습니다
- 나무 화면은 15초마다 새 카드를 자동으로 반영합니다 (행사장 화면에 띄워두기 좋아요)
- 도배 방지(작성 횟수 제한)는 들어 있지 않습니다. 부적절한 카드는 관리자 화면의 "카드 관리"에서 삭제하세요
