# 수학 원정대

고등학교 입학 전에 중학교 3년 수학을 게임처럼 단계별로 총정리하는 자기주도 학습 사이트입니다.

- 개념 29개 (중1 10개, 중2 10개, 중3 9개), 개념마다 3단계 × 5문제
- 4문제 이상 맞히면 다음 단계가 열리고, 3단계를 모두 클리어하면 아이템을 얻습니다
- 개념별 문제은행: 문제가 매번 새로 만들어지므로 원하는 만큼 풀 수 있습니다
- 개념마다 정승제 선생님 강의를 찾는 유튜브 검색 링크
- 학습 기록(레벨, 별, 아이템)은 기기의 브라우저(localStorage)에 저장됩니다

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나, 이 폴더를 GitHub Pages·Netlify·Vercel 같은 정적 호스팅에 그대로 올리면 됩니다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `index.html`, `style.css` | 화면 뼈대와 디자인 |
| `js/lib.js` | 문제 생성 도구(수식 표기, 정답 판정, 조사 처리) |
| `js/m1.js`, `js/m2.js`, `js/m3.js` | 학년별 개념 설명과 문제 생성기 |
| `js/app.js` | 지도·문제 풀이·레벨·아이템 등 게임 진행 |

새 개념을 추가하려면 `js/m*.js`에 `MQ.concepts.push({...})` 항목을 하나 더 넣으면 됩니다.
