# 수학 원정대

몬스터와 싸우며 중학교 3년 수학을 정복하는 수학 RPG입니다. 고등학교 입학 전 총정리용 자기주도 학습 사이트입니다.

- 개념 29개(중1 10개, 중2 10개, 중3 9개)가 각각 몬스터 한 마리입니다. 몬스터마다 3단계 전투, 전투마다 5문제입니다
- 정답이면 공격, 오답이면 반격당해 하트를 잃습니다. 4문제 이상 맞히면 승리, 3단계를 모두 이기면 무기를 얻습니다
- 콤보·크리티컬, 스피드 보너스, 골드, 상점(힌트·캐릭터), 오늘의 임무, 월드 보스전(10연속 전투)
- 무한 던전(문제은행): 문제가 매번 새로 만들어지므로 원하는 만큼 풀 수 있습니다
- 몬스터마다 공략집(핵심 개념)과 정승제 선생님 강의를 찾는 유튜브 검색 링크
- 게임 기록은 기기의 브라우저(localStorage)에 저장됩니다

## 실행

빌드 과정이 없는 정적 사이트입니다. `index.html`을 브라우저로 열거나, 이 폴더를 GitHub Pages·Netlify·Vercel 같은 정적 호스팅에 그대로 올리면 됩니다.

## 구조

| 파일 | 내용 |
| --- | --- |
| `index.html`, `style.css` | 화면 뼈대와 디자인 |
| `js/lib.js` | 문제 생성 도구(수식 표기, 정답 판정, 조사 처리) |
| `js/m1.js`, `js/m2.js`, `js/m3.js` | 학년별 개념 설명과 문제 생성기 |
| `js/app.js` | 지도·전투·보상·상점 등 게임 진행 |

새 개념을 추가하려면 `js/m*.js`에 `MQ.concepts.push({...})` 항목을 하나 더 넣으면 됩니다.
