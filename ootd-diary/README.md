# OOTD 다이어리

내 옷장을 사진으로 등록하고, 매일 입은 옷을 캘린더에 기록하고, 오늘 날씨에 맞는 코디를 추천받는 웹앱.

## 기능

- **옷장** — 사진·카테고리·계절·두께·색상으로 옷 등록, 카테고리/계절별 필터, 착용 횟수와 1회당 가격
- **캘린더** — 날짜별로 입은 옷, 착샷, 메모 기록. 이달의 활용률과 자주 입은 옷
- **스타일리스트 추천** — 현재 기온·강수·일교차, 계절, 최근 착용 이력, 색 조합을 고려한 코디 3벌
- **구매내역 가져오기** — 주문 목록 텍스트 / CSV / JSON을 붙여넣으면 상품명으로 카테고리·계절·두께·색상 자동 분류
- **백업** — JSON 파일로 내보내기 / 복원

## 실행

빌드 과정이 없는 정적 사이트입니다.

```bash
cd ootd-diary
python3 -m http.server 4173   # http://localhost:4173
```

Vercel · Netlify · GitHub Pages 등 정적 호스팅에 이 폴더를 그대로 올리면 됩니다.

## 데이터

- 옷 사진과 기록은 서버 없이 **브라우저(IndexedDB)** 에만 저장됩니다. 기기 간 동기화는 되지 않으니 백업 파일을 이용하세요.
- 날씨는 [Open-Meteo](https://open-meteo.com) 무료 API를 사용합니다(키 불필요). 위치는 기본 서울이며 도시 검색·현재 위치로 바꿀 수 있습니다.

## 구조

```
index.html / styles.css
js/app.js       화면과 동작
js/store.js     IndexedDB 저장소
js/stylist.js   날씨 + 코디 추천 로직
js/importer.js  구매내역 파싱 + 자동 분류
js/util.js      상수, 이미지 처리
js/sample.js    샘플 옷장
```
