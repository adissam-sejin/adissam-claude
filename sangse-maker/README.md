# 상세메이트 — AI 상세페이지 제작 사이트 (MVP)

상품 사진과 장점 몇 줄을 넣으면 AI(Claude)가 **기획 → 카피 → 디자인**까지 상세페이지를 만들어 주는 웹 서비스입니다.
1분상세, 후커블, 상세뚝딱 같은 서비스의 핵심 흐름을 참고해 직접 구현했습니다.

## 주요 기능

| 단계 | 기능 |
|---|---|
| 1. 상품 정보 | 사진 업로드(최대 8장, 자동 리사이즈) · **사진으로 자동 채우기**(카테고리/특징/타깃/USP/브랜드 컬러 추천) · 스타일 템플릿 4종 · 브랜드 컬러 |
| 2. 기획 초안 | 콘셉트·후킹 카피·섹션 구성을 먼저 보여줌 → 순서 변경/추가/삭제/메시지 수정, 다시 만들기 |
| 3. 생성 | 기획 초안대로 카피 + 사진 배치 + 컬러 테마가 들어간 상세페이지 JSON 생성 |
| 4. 편집 | 글자 클릭해서 바로 수정 · **섹션 선택 후 말로 수정**("더 짧게") · 사진 교체 · 섹션 이동/복제/삭제 · 블록 12종 추가 · 스타일/컬러 변경 · 되돌리기(Ctrl+Z) |
| 5. 내보내기 | 채널 규격(스마트스토어 860 / 쿠팡 780 / 토스 1080 / G마켓 860 / 옥션 980 / 11번가 800) · JPG/PNG · 섹션별 조각 + 전체 한 장을 zip 으로 |

작업 내용은 브라우저(IndexedDB)에 자동 저장되고, `최근 작업`에서 이어서 할 수 있습니다.

## 실행 방법

```bash
cd sangse-maker
npm install
cp .env.example .env.local   # ANTHROPIC_API_KEY 입력
npm run dev                  # http://localhost:3000
```

- `ANTHROPIC_API_KEY` 를 비워 두면 **데모 모드**로 동작합니다 (샘플 결과로 전체 화면 흐름 체험 가능).
- API 키는 https://console.anthropic.com 에서 발급합니다.

## 구조

```
app/
  page.tsx               랜딩 페이지
  create/page.tsx        제작 마법사 (입력 → 기획 → 생성 → 편집)
  api/analyze            사진 → 상품 정보 자동 채우기 + USP
  api/plan               기획 초안
  api/generate           상세페이지 생성
  api/revise             섹션 하나 말로 수정
components/
  DetailPage.tsx         상세페이지 렌더러 (860px 기준, 섹션 12종)
  Editor.tsx             편집기
lib/
  schema.ts              섹션/테마/기획 JSON 스키마 (zod, 구조화 출력에 사용)
  prompts.ts             AI 프롬프트 (카피 원칙, 과장·허위 표현 금지 규칙)
  claude.ts              Claude API 호출 (구조화 출력, 오류 처리, 거절 시 폴백)
  export.ts              이미지 내보내기 (전체 캡처 후 섹션 경계로 분할)
  channels.ts            채널 규격, 스타일 템플릿
```

- 모델: `claude-opus-5-5` (구조화 출력으로 항상 스키마에 맞는 JSON 을 받음)
- 정책상 거절될 경우 서버 측 폴백(`fallbacks: "default"`)이 켜져 있습니다.
- AI 는 확인되지 않은 수치·인증·후기를 지어내지 않고 `[입력]` 자리표시로 남기도록 지시되어 있습니다.

## 다음 단계 (실서비스로 가려면)

1. **회원가입/로그인** — Supabase Auth 등. 프로젝트를 서버 DB 에 저장해 여러 기기에서 이어 하기.
2. **결제·크레딧** — 토스페이먼츠/포트원으로 구독 + 크레딧 차감 (생성 1회 = N 크레딧, 기획 초안은 무료).
3. **AI 연출 이미지 생성** — 상품 사진으로 사용 장면·배경 연출 컷 생성, 배경 제거 (이미지 생성 API 연동).
4. **GIF/움직이는 컷**, **다국어 동시 생성**, **레퍼런스 페이지 스타일 반영**.
5. **배포** — Vercel 에 올리고 환경 변수에 `ANTHROPIC_API_KEY` 설정. 생성 API 는 최대 300초가 걸릴 수 있어 함수 타임아웃을 늘려야 합니다.
6. 사용량 제한(레이트 리밋)과 API 비용 모니터링.
