# 하나님과의 대화

내 마음을 적고 그분의 말씀을 받아 적는 기록장. `https://godtalk.netlify.app`

## 이번 판에서 달라진 것

- **카카오 로그인** — 사람마다 자기 기록만 보입니다. 로그인하지 않으면 서버가 아무것도 내주지 않습니다.
- **기록 보관 두 가지** — 기본은 이 앱 서버(Netlify)에 암호화해 보관하고, 설정에서 **내 노션**을 연결하면 자기 노션 데이터베이스에만 저장합니다. 연결할 때 앱 서버에 쌓인 기록을 노션으로 옮길 수 있습니다.
- **예전 기록 그대로** — 처음부터 쓰던 노션 데이터베이스(GodTalk)는 저장 모양을 하나도 바꾸지 않았습니다. 주인 계정이 한 번 이어받으면 예전 글이 그대로 보입니다.
- **잠금** — 숫자 비밀번호를 서버에서 검사합니다. 다섯 번 틀리면 5분 쉬고, 잊으면 카카오 재인증으로 풉니다.
- **앱처럼** — 홈 화면 아이콘, 전체 화면, 성경은 기기에 담아 두어 인터넷 없이도 찾고, 끊긴 동안 쓴 글은 연결되면 저장됩니다.
- **메신저 같은 대화창** — 하나님 말씀은 왼쪽(프로필과 이름), 내 말은 오른쪽. 입력칸은 아래 하나이고 「내 마음 / 하나님 말씀」을 눌러 바꿉니다.
- **밝은/어두운 화면** — 밝은 「따뜻한 편지지」, 어두운 「새벽 하늘」. 설정에서 고르거나 기기 설정을 따릅니다.
- **이모지 남기기** — 말풍선을 누르면 ❤️ 👍 🥹 🙏 ✅ 중 하나를 남기고, 「마음에 남긴 말」에서 이모지별로 모아 봅니다. 노션에는 그 줄 끝에 이모지가 붙습니다.
- **PDF로 저장** — 기간을 고르면 대화 전체를 이모지까지 담아 대화창 모양 그대로 PDF 한 파일로 만듭니다 (기기 안에서 만들어 서버로 보내지 않습니다).
- **기록 기능** — 대화 찾기, 글 고치기, 이어 쓴 날 수, 성경 장별 읽기, 글 파일(.txt) 내려받기.
- **글자 크기** — 작게부터 아주 크게까지 다섯 단계.
- **캐릭터** — 프로필·앱 아이콘·파비콘은 `design/character/c4-blue.png` 한 장에서 만듭니다. 바꾸려면 `python3 tools/make_icons.py 그림.png`.

## 폴더

```
godtalk/
├─ public/                  화면 (이 폴더만 인터넷에 공개됩니다)
│  ├─ index.html            앱 화면 전체 — 색은 위쪽 :root 값만 고치면 됩니다
│  ├─ sw.js                 오프라인 지원
│  ├─ manifest.webmanifest  홈 화면 아이콘·이름
│  ├─ icons/                아이콘
│  ├─ bible.json            개역개정 31,088절
│  └─ _headers, robots.txt  보안 헤더, 검색엔진 차단
├─ netlify/functions/api.mjs  서버 (로그인·저장). 비밀값은 여기에 적지 않습니다
├─ netlify.toml
├─ test/                    시험 (가짜 카카오·가짜 노션으로 돌립니다)
├─ design/                  디자인 시안과 캐릭터 원본
└─ tools/make_icons.py      캐릭터 그림으로 아이콘·프로필 만들기
```

## 처음 한 번 해 둘 일

### 1. 카카오 로그인 만들기 (10분)

메뉴 이름은 카카오가 가끔 바꿉니다. 화면이 다르면 비슷한 이름을 찾으면 됩니다.

1. <https://developers.kakao.com> 에 카카오 계정으로 로그인 → **앱** 만들기 (이름: 하나님과의 대화)
2. **[앱] > [플랫폼 키] > [REST API 키]** 로 들어가서
   - **REST API 키** 값을 복사해 둡니다
   - **리다이렉트 URI**에 아래 주소를 그대로 등록합니다
     `https://godtalk.netlify.app/api/auth/kakao/callback`
   - **클라이언트 시크릿** 코드를 복사해 둡니다 (기본으로 켜져 있습니다)
3. **[카카오 로그인] > [사용 설정] > [상태]** 를 **ON**
4. (선택) **[카카오 로그인] > [동의항목]** 에서 **닉네임**을 켜면 설정 화면에 이름이 보입니다. 안 켜도 로그인은 됩니다.

### 2. Netlify에 값 넣기

Netlify → godtalk → **Project configuration → Environment variables**

| Key | 값 | 비고 |
|---|---|---|
| `KAKAO_REST_KEY` | 카카오 REST API 키 | 직접 넣기 |
| `KAKAO_CLIENT_SECRET` | 카카오 클라이언트 시크릿 | 직접 넣기 |
| `NOTION_TOKEN` | 노션 시크릿 (`ntn_…`) | **새로 발급한 값으로 바꾸기** — 아래 참고 |
| `NOTION_DB` | 노션 데이터베이스 ID | 넣어 둠 |
| `APP_SECRET` | 긴 무작위 글자 | 넣어 둠. **절대 바꾸거나 지우지 마세요** |
| `OWNER_CODE` | 예전 기록 이어받기 코드 | 넣어 둠. 이어받은 뒤 지워도 됩니다 |

- `APP_SECRET`은 기록을 암호화하는 열쇠입니다. 바꾸면 앱 서버에 보관된 모든 사람의 기록을 다시 열 수 없습니다.
- 값을 바꾼 뒤에는 **다시 배포해야** 적용됩니다.

### 3. 노션 시크릿 새로 발급하기 (꼭)

예전 판은 서버 파일이 사이트에 그대로 공개되어 있었고 그 안에 노션 시크릿이 적혀 있었습니다. 그 값은 더 쓰면 안 됩니다.

1. <https://www.notion.com/profile/integrations> → 쓰던 연결 선택 → 시크릿 **다시 발급(Refresh / Regenerate)**
2. 새 값을 Netlify의 `NOTION_TOKEN`에 덮어 넣기

### 4. 배포한 뒤 — 예전 기록 이어받기

카카오로 로그인한 다음, 아래 주소를 **한 번만** 엽니다. (`코드`는 Netlify의 `OWNER_CODE` 값)

```
https://godtalk.netlify.app/?claim=코드
```

"예전 기록을 이어받았어요"가 뜨면 끝입니다. 한 계정만 이어받을 수 있고, 그 뒤로는 어느 기기에서든 카카오로 로그인하면 예전 기록이 보입니다.

## 다른 사람이 쓸 때

- 주소만 알려 주면 됩니다. 카카오로 로그인하면 자기만의 빈 기록장이 열립니다.
- 노션을 쓰는 사람은 **설정 → 기록 보관 → 내 노션에 연결하기**에서 자기 시크릿과 데이터베이스 주소를 넣습니다. 시크릿은 암호화해 보관합니다.
- 계정을 지우면(설정 맨 아래) 앱 서버에 보관된 그 사람의 기록이 모두 지워집니다.
- 여러 사람의 신앙 기록을 맡게 되므로, 널리 알리기 전에 "무엇을 어디에 보관하는지" 한 줄 안내를 준비해 두면 좋습니다.

## 고칠 때

```
npm install
node test/api.test.mjs        # 서버 시험
node test/dev-server.mjs      # http://localhost:8788 에서 가짜 카카오·노션으로 써 보기
node test/e2e.mjs             # 화면 시험 (dev-server를 켜 둔 채로, Playwright 필요)
```

나: 오늘은 마음이 자꾸 무너져요  오전 06:30
